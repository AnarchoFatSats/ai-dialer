# AI Dialer - AWS ECS Environment Configuration Guide
# Full AI Implementation Setup

============================
AWS Configuration
============================
AWS_REGION=us-east-1
AWS_ACCOUNT_ID=your-aws-account-id

============================
Database Configuration
============================
# For AWS RDS PostgreSQL instance
DATABASE_URL=postgresql+asyncpg://username:password@your-rds-endpoint:5432/aidialer

============================

============================
# Get from: https://console.anthropic.com/

# Get from: https://console.deepgram.com/

============================
AWS Secrets Manager Setup Commands
============================
# Run these commands to store secrets securely:

aws secretsmanager create-secret --name "ai-dialer/database-url" --secret-string "postgresql+asyncpg://username:password@your-rds-endpoint:5432/aidialer" --region us-east-1

aws secretsmanager create-secret --name "ai-dialer/anthropic-api-key" --secret-string "sk-ant-your-anthropic-api-key" --region us-east-1

aws secretsmanager create-secret --name "ai-dialer/openai-api-key" --secret-string "sk-your-openai-api-key" --region us-east-1

aws secretsmanager create-secret --name "ai-dialer/deepgram-api-key" --secret-string "your-deepgram-api-key" --region us-east-1

aws secretsmanager create-secret --name "ai-dialer/elevenlabs-api-key" --secret-string "your-elevenlabs-api-key" --region us-east-1

============================
Quick Start Instructions
============================
1. Install Docker Desktop (if not already installed)
2. Get API keys from AI service providers (see links above)
3. Run AWS Secrets Manager commands with your real values
4. Execute deployment: .\deploy-ecs-full-ai.ps1
5. Wait 2-3 minutes for deployment to complete
6. Test AI functionality at the provided endpoint

============================
Required AWS Permissions
============================
Your AWS user/role needs:
- ECR full access (for pushing Docker images)
- ECS full access (for deploying containers)
- EC2 read access (for VPC/subnet discovery)
- Secrets Manager read access (for retrieving API keys)
- CloudWatch Logs write access (for application logs)
- IAM list/pass role (for ECS task roles)
